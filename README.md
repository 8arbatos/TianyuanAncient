# 天元遗迹 TianyuanAncient 
## 类型：2D俯视角即时战斗修仙 Roguelite + 洞府养成
## 平台目标：PC(Windows)
## 开发引擎：Godot
## 操作说明
### 非战斗状态
| 按键 | 动作 | 描述 |
|------|------|------|
| W、A、S、D | 移动 | 最经典的移动方式，无需多言 |
| E | 交互 | 是的，当你感觉你现在需要按些什么键但是不知道具体按哪个键，那么请按下E键！ |
| ESC | 暂停 | 既可以暂停也可以解除暂停 |

### 战斗状态
| 按键 | 动作 | 描述 |
|------|------|------|
| W、A、S、D | 移动 | 最经典的移动方式，无需多言 |
| 鼠标点击 | 移动 | 第二套移动方式，拥有自动寻路的功能 |
| E | 交互 | 是的，当你感觉你现在需要按些什么键但是不知道具体按哪个键，那么请按下E键！|
| ESC | 暂停 | 既可以暂停也可以解除暂停 |
| F、SHIFT、K | 闪避 | 通过向当前移动方向快速突进一下来实现闪避。注意，当前不处于移动状态时无法闪避 |
| SPACE、J | 普通攻击 | 只要施放就会进入移速变为原来一半的~~攻击~~乌龟模式。但是，可以通过闪避来离开攻击模式（冷知识，不动时按闪避键可以直接离开攻击模式并且不消耗体力） |
| Q | 开关优先索敌 | 会有一个小黄点显示在优先索敌的目标上。（不处于优先索敌状态时默认索敌目标为距玩家最近的敌人） |
| R | 切换索敌目标 | 假如有第二个敌人甚至更多敌人的话，可以切换优先索敌目标 |
| B、TAB | 打开、关闭背包 | 可以打开一个称之为储物戒的背包系统 |
| 上下左右方向键 | 法诀输入 | 从某超级地球剽窃来加以修改的法诀输入系统，可以输入法诀，已经输入的法诀会显示在UI下方的法诀输入框内 |
| ENTER | 释放法诀 | 假如当前输入的法诀正确，则可以释放强大的法术！ |
| BACKSPACE | 清空法诀输入 | 可以将已经输入的法诀清空，但是也会消耗体力 |
