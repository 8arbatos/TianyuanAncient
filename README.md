# 天元遗迹 TianyuanAncient 
## 类型：2D俯视角即时战斗修仙 Roguelite + 洞府养成（**必不可少的种田环节！！！**）
## 平台目标：PC
## 开发引擎：Godot
## 操作说明
### 非战斗状态
| 按键 | 动作 | 描述 |
|------|------|------|
| W、A、S、D | 移动 | 最经典的移动方式，无需多言 |
| E | 交互 | 是的，当你感觉你现在需要按些什么键但是不知道具体按哪个键，那么请按下E键！（很可能是交互） |
| ESC | 暂停 | 本来ESC既可以暂停也可以解除暂停，但是懒狗作者还没有想到可以在场景暂停后按下ESC键有反应的办法(～﹃～)~zZ |

### 战斗状态
| 按键 | 动作 | 描述 |
|------|------|------|
| W、A、S、D | 移动 | 最经典的移动方式，无需多言 |
| 鼠标点击 | 移动 | 第二套移动方式，是伟大的巡航系统！如此伟大的巡航系统给我这个半个机器人专业的学生看哭了(╥﹏╥) |
| E | 交互 | 是的，当你感觉你现在需要按些什么键但是不知道具体按哪个键，那么请按下E键！（很可能是交互） |
| ESC | 暂停 | 本来ESC既可以暂停也可以解除暂停，但是懒狗作者还没有想到可以在场景暂停后按下ESC键有反应的办法(～﹃～)~zZ |
| F、SHIFT | 闪避 | 通过向当前移动方向快速突进一下来实现闪避，向前闪也是闪！高达0.3秒的无敌帧可以让你堪比山里灵活的狗！注意，当前不在移动时可能无法闪避哦 |
| SPACE | 普通攻击 | 只要施放就会进入移速变为原来一半的~~攻击~~乌龟模式。但是，可以通过闪避来离开攻击模式（冷知识，不动时按闪避键可以直接离开攻击模式并且不消耗体力） |
| Q | 开启优先索敌 | 无需多言，bug大王！会有一个小黄点显示在优先索敌的目标上。（不处于优先索敌状态时默认索敌目标为距玩家最近的敌人） |
| R | 切换索敌目标 | bug二王！假如有第二个敌人甚至更多敌人的话，可以切换索敌目标 |
